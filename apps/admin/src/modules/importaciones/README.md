# Importar PDF

Subida de PDF editorial, revisión de canciones convertidas y publicación de borradores.

## Endpoints de la API

- `GET /api/v1/staff/importaciones`
- `POST /api/v1/staff/importaciones`
- `GET /api/v1/staff/importaciones/{id}`
- `POST /api/v1/staff/importaciones/{id}/publicar`
- `POST /api/v1/staff/importaciones/{id}/reintentar`

- **Estado:** marcador de posición. La conexión a la API se hace en el siguiente paso.

# Artistas y catálogo

Álbumes, canciones y ChordPro de los artistas que administras.

## Endpoints de la API

- `GET /api/v1/mis-artistas`
- `GET /api/v1/mis-artistas/{artistId}`
- `GET /api/v1/mis-artistas/{artistId}/canciones/{songId}`
- `POST /api/v1/mis-artistas/{artistId}/pistas/{trackId}/master (manager)`

- **Estado:** marcador de posición. La conexión a la API se hace en el siguiente paso.

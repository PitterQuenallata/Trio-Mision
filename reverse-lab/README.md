# Reverse Lab

Laboratorio de ingeniería inversa y análisis de aplicaciones de terceros, con fines exclusivamente educativos y de investigación autorizada.

## Estructura

- `projects/` — un directorio por aplicación analizada. Usar `projects/_template/` como plantilla.
- `tools/` — utilidades y scripts de apoyo (`tools/scripts/`).

## Límites éticos (obligatorios)

- Solo análisis de aplicaciones **autorizadas** (propias, de código abierto, o con permiso explícito).
- **No** robar credenciales ni tokens.
- **No** extraer secretos ni claves de API.
- **No** eludir pagos ni mecanismos de licencia.
- **No** acceder a datos privados de usuarios.
- Los APK/IPA de terceros **no se suben a git** (ignorados por `.gitignore`).
- Las grabaciones de evidencia grandes (`evidence/recordings/`) están excluidas de git.
